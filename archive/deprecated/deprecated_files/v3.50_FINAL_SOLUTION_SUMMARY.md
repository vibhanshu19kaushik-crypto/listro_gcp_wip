## Problem Diagnosed
Images being returned included:
- **71I53evweVL** ✅ Product gallery (CORRECT)
- **81EJskJGWzL** ✅ Product variant (CORRECT)
- **41OGSnetIXL** ❌ Q&A/Review image (WRONG!)
- **51fAd+eU0eL** ❌ Customer uploaded (WRONG!)

## Root Cause Found

**backend/scraper.py** had 4 image extraction methods:
- Method 1: `dynamic_images = image_block.find_all(...)` ✅ Correct
- Method 2: `script_tags = soup.find_all('script', ...)` ⚠️ Page-wide
- **Method 3: `img_tags = soup.find_all('img', src=True)` ❌ FINDS ENTIRE PAGE!**
- **Method 4: Redundant imageBlock search ❌ DUPLICATE!**

When amz_scraper returned images → Used those (fine)
When amz_scraper returned empty → Fell back to scraper.py → Got review images (bad!)

## Solution Implemented (v3.50)

### Changed backend/scraper.py

```diff
# BEFORE (Method 3 - WRONG)
- img_tags = soup.find_all('img', src=True)  # ← Searches ENTIRE PAGE

# AFTER (Method 3 - CORRECT)
+ if image_block:
+     img_tags = image_block.find_all('img', src=True)  # ← ONLY imageBlock
```

### Result

**ALL extraction methods now use imageBlock only:**
- ✅ Method 1: Dynamic images from imageBlock
- ✅ Method 2: Scripts about imageBlock content
- ✅ Method 3: IMG tags within imageBlock
- ✅ Method 4: Removed (was redundant)
